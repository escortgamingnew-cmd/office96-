# Research-raw — չստուգված հետքերի պահեստ

Այստեղ հիմնադիրը գցում ա արտաքին գործիքների արդյունքները՝ ChatGPT Deep
Research, Grok և այլն (PDF կամ md)։ Ֆայլի անունը՝
`ԱԱԱԱ-ԱԱ-ՕՕ-աղբյուր-թեմա.md` (օր՝ `2026-09-08-chatgpt-math-sdk.md`)։

## Գլխավոր կանոնը

**Այս ֆոլդերի ամեն ինչ ՉՍՏՈՒԳՎԱԾ ա — հետք ա, ոչ ճշմարտություն։**
ChatGPT-ն ու Grok-ը թիմի անդամ չեն. արտաքին գործիքներ են, որոնց խոսքը
հուշում ա, աղբյուր չի։ Ոչ ոք այս ֆոլդերի նյութի վրա կոդ, մաթ մոդել կամ
թասկ չի կառուցում։

## Հոսքը

1. Հիմնադիրը raw ֆայլ ա գցում այստեղ։
2. Research-ի պատասխանատուն (ղեկավարը՝ Սևակ) ամեն պնդում ստուգում ա
   **պաշտոնական աղբյուրի** դեմ. stake-engine.com, պաշտոնական
   դոկումենտացիա, SDK repo-ներ։
3. Ստուգվածը մտնում ա `docs/stake-engine/` — հղումով ու
   «ստուգված՝ ԱԱԱԱ-ԱԱ-ՕՕ» նշումով։
4. Հերքվածը raw ֆայլում պիտակվում ա **«ՀԵՐՔՎԱԾ՝ ամսաթիվ, ինչու»** —
   որ ոչ ոք դրա վրա չկառուցի։
5. Ո՛չ հաստատվող, ո՛չ հերքվող հարցերը գնում են `questions.md` —
   հիմնադիրը տանում ա արտաքին գործիքներին, պատասխանը բերում ա, ու այն
   ԴԱՐՁՅԱԼ ստուգվում ա (կետ 2)։

## Կոշտ բացառություն

Կոդային ճշգրտության հարցերը — Math SDK API, book ձևաչափ, upload
validation — **միայն** պաշտոնական դոկից/repo-ից են մտնում
docs/stake-engine/։ Միջնորդ (ChatGPT/Grok/blog) էս հարցերում ընդհանրապես
հաշվի չի առնվում։
