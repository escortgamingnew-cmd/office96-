# Run Dady — Ասեթների սպեց դիզայների համար (v1)

Գրված՝ 2026-09-10, Սևակ (lead)՝ Արամի (դիզայներ) համար։ Հիմքը՝ պարիտետ
build-ը (prototype/pixi-feel), պրոտոյի վերլուծությունը ու Stake-ի
ստուգված կանոնները։ Հարց ունես՝ product չաթ։

## 0. Ամենակարևոր միտքը. 3D-ով ես աշխատում, 2D ենք ship անում

Դու ասեթները **սարքում ես 3D-ով** (Blender/ինչով հարմար ա) — ճիշտ ոնց
պրոտոյում GLB-ներ էին։ Բայց խաղի մեջ մտնում են **2D bake-եր**. 3D մոդելը
ռենդերվում ա մեր ֆիքսված կամերայի ռակուրսով ու դառնում ա sprite/տեքստուրա։
Դրանով ստանում ենք 3D-ի տեսքը՝ առանց մոբայլը տաքացնելու (D-001)։
3D source ֆայլերը (.blend/.glb) պահում ենք — bake-ը կարանք միասին անենք
Blender-ով, ես pipeline-ը կսարքեմ։

## 1. Կամերան — մեկ հատ ա, ու սա ա

Ամեն ասեթ երևալու ա ՄԻԱՅՆ էս ռակուրսից (պրոտոյի կամերան).

- Դիրք. ճամփի կենտրոնում, **բարձրությունը 4.5 մ** (2-րդ հարկի պատուհանի
  մակարդակ), FOV 55° (արագության վրա բացվում ա մինչև ~69°)։
- Նայում ա ուղիղ ճամփի երկայնքով դեպի հորիզոն. օբյեկտները ծնվում են
  հորիզոնում ու մոտենալով անցնում կադրից դուրս՝ ձախ/աջ եզրերով։
- Հետևանք. շենքերը երևում են **դիմացից + թեթև վերևից**, մեքենաները՝
  **հետևից/հետև-կող 3/4**, հերոսը՝ **դիմացից** (վազում ա դեպի մեզ)։

## 2. Ասեթների ցուցակը՝ ըստ կատեգորիայի

### 2.1 Շենքեր (ամենամեծ ծավալը) — ՈՉ ամբողջական ռենդեր, այլ ԵՐԵՍՆԵՐ

Engine-ը շենքը հավաքում ա 3 տեքստուրայից (ֆասադ + կողային պատ + տանիք)
ու ինքն ա հեռանկարը տալիս։ Քեզնից ամեն շենքի համար.

| Երես | Չափ (px) | Նշում |
|---|---|---|
| Ֆասադ (ճամփի կողմը) | 512 × 640–1024 | պատուհաններ, մուտք, դետալ |
| Կողային պատ | 256 × նույն բարձր. | ավելի պարզ, կրկնվող |
| Տանիքի շերտ | 256 × 128 | վերևից թեթև երևում ա (կամերան 4.5մ ա) |

- **Քանակ.** 8–10 տարբեր շենք (լայն/նեղ/բարձր/ցածր խառնուրդ) + **1
  հյուրանոց** (մեկնարկի landmark-ը, պրոտոյից)։
- Վառվող պատուհանները՝ ֆասադի մեջ baked (հետագայում գիշեր/ցերեկի համար
  կարանք առանձին «լույս» շերտ ուզենք — v2)։
- 3D-ով սարքի, մենք կռենդերենք երեսները ուղղահայաց (orthographic)։

### 2.2 Մեքենաներ — 3D-ից sprite-strip

- Ռակուրսներ. **հետև**, **հետև-կող 3/4**, **կող** (3 կադր. ձախ կողմի
  համար հայելում ենք engine-ում)։ Կադրը ~320px լայն, թափանցիկ ֆոն։
- **Գունավորումը մերն ա.** մեքենան տուր **չեզոք բաց մոխրագույն** կուզովով
  (դետալները՝ ապակի, անիվ, լույսեր՝ իրենց գույնով) — engine-ը tint-ով
  10 գույն ա սարքում մեկից, ասեթ չենք բազմացնում։
- Քանակ. 2–3 մոդել (sedan, van/pickup, մի «համով» retro)։ Պրոտոյի GLB-ն
  հանած ունենք (docs/reference/assets/car-default.glb) — ուզես դրանից
  սկսի, ուզես նորը սարքի։

### 2.3 Կերպարներ — spritesheet-եր (ամենազգայուն մասը)

| Կերպար | Ինչ ա պետք | Կադր | Չափ |
|---|---|---|---|
| Պապի + կինը (ունենք) | վազքի ցիկլ | 20 (4×5) | 500×500 |
| Պապի + կինը | idle «շնչող» կանգնած | 6–8 | 500×500 |
| Պապի + կինը | բռնված/caught պոզա | 2–4 | 500×500 |
| **Հետապնդողը** (չկա՛) | վազքի ցիկլ դեպի կամերա | 12–20 | 500×500 |
| Հետապնդողը | catch/բռնելու շարժում | 4–6 | 500×500 |

- Հետապնդողը էսօրվա ամենամեծ բացն ա — build-ում silhouette placeholder ա։
- Ոճն ու լույսը ՊԻՏԻ բռնեն Պապիի եղած sheet-ի հետ (նույն «Pixar-ային»
  ծավալային ոճը, նույն ուղղության լույս)։

### 2.4 Փողոցի դետալներ — billboard sprite-եր (հարթ, մեկ ռակուրս)

- Լապտեր՝ 1 sprite (128×480, glow-ը baked)։ Ծառ՝ 2–3 վարիանտ։ Թուփ՝ 2։
- **Գովազդային billboard-ների արտեր՝ 4–6 հատ** (512×256)։ Խաղի աշխարհի
  հումորով, ԱՄԲՈՂՋՈՎԻՆ հորինված բրենդներ — ոչ մի իրական լոգո/IP,
  ոչ մի Stake նշան (կանոն ա, մերժման հիմք)։
- Ըստ ցանկության. հիդրանտ, նստարան, աղբաման — «քաղաքը շնչա» մանրուքներ։

### 2.5 Ֆոն ու ճամփա

- Հեռվի քաղաքի silhouette՝ tileable շերտ 1024×170 (հիմա կոդով ա, արտով
  ավելի լավը կլինի)։ Երկնքի գրադիենտի գույները՝ քո ընտրություն (հիմա՝
  պրոտոյի ցերեկայինը)։
- Ասֆալտ + մայթի tile տեքստուրա (256×256, seamless)։

### 2.6 UI արտ (2-րդ փուլ) ու Tile փաթեթ (submission)

- UI-ն հիմա CSS ա ու աշխատում ա — արտ-անցումը հետո։
- Stake-ի submission-ին պետք ա գալու՝ **tile bg + fg (միասին ≤3MB) +
  provider logo** (T-0005-ի լոգոն) — բարձր որակի PNG/JPG։ v2-ի գործ ա,
  բայց իմացած եղի։

## 3. Լույսի ու ոճի կանոնները (որ ամեն ինչ իրար բռնի)

1. **Մեկ լույս ամբողջ աշխարհի համար.** ընտրի ուղղությունը (առաջարկս՝
   վերև-ձախից, թեթև տաք) ու ԲՈԼՈՐ ասեթները դրանով ռենդերի։
2. Ստվերները փափուկ, գետնի ստվեր ՉԻ պետք ասեթի մեջ — engine-ը blob
   shadow ա դնում։
3. Ոճային մեկ ընտանիք. Պապիի sheet-ը էտալոնն ա։ Stake-ի կանոնը հիշի.
   «անհամաձայն art» ու «generic AI ասեթներ» = 1★։ Բենչմարկներդ՝
   Cut n Crash, Angry Balls, Drop the Boss։

## 4. Տեխնիկական պահանջներ (export)

- Ձևաչափ. **WebP** (որակ 80–90)՝ փափուկ պատկերների, PNG՝ սուր եզրերի։
  Թափանցիկ ֆոն sprite-երին։
- Անվանում. `կատեգորիա_անուն_վարիանտ_ռակուրս.webp`
  (օր. `building_hotel_a_facade.webp`, `car_sedan_rear34.webp`)։
- **Բյուջե. ամբողջ ասեթ-փաթեթը ≤ 8–10 MB։** Հիմա խաղը 0.72 MB ա,
  Pixi-ն՝ 0.78 MB. արագ load-ը 3★-ի պաշտոնական չափանիշ ա — ամեն MB
  հաշված ա։ In-game MB-ցուցիչ էլ ա գալիս (Տիգրանին հանձնարարված ա)։
- Հանձնում. ֆայլերը գցում ես `docs/design/drops/<ամսաթիվ>/` կամ ուղիղ
  չաթ (📎)։ 3D source-երը՝ `docs/design/src3d/`։

## 5. Հերթականությունը (իմ առաջարկը — դու ես որոշում)

1. **Հետապնդողի կերպարը** — խաղային ամենամեծ բացը
2. **Շենքերի 3–4 ֆասադ + հյուրանոցը** — աշխարհի դեմքը
3. **Մեքենա 1 մոդել** (չեզոք գույնով)
4. Billboard-ների արտերը (4 հատ)
5. Ծառ/լապտեր/մանրուքներ
6. Ֆոնի silhouette + ասֆալտ
7. UI արտ + tile փաթեթ + լոգո (T-0005)
