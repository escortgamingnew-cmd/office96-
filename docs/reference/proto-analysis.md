կոդի ուղիղ ընթերցում։ Եզրակացությունը վերջում։

## Մեխանիկան (կոդից, ոչ հիշողությունից)

- **Hold-to-run.** Մեկ կանաչ կոճակ՝ «Place Bet» ↔ «Run! Daddy» մորֆով
  (DOM/CSS խորեոգրաֆիա. stake-զոնան փլվում ա, չիպերը թռնում են,
  կոճակը spring-ով ձգվում)։ Պահած ժամանակ վազում ա, բաց թողած՝ կանգնում։
- **Մուլտիպլիկատոր.** `curMult = 1 + dist * MULT_RATE` — տարածությունից ա։
- **CASH OUT** երկրորդ կոճակով mid-run → win = BET × curMult, rewind
  անիմացիա (աշխարհը ետ ա հոսում կամերայի կողքով)։
- **Բռնվելը.** `lose()`՝ հետապնդողը մտնում ա կադր կողքից՝ «ճանապարհի
  օբյեկտի պես», անցնում առաջ ու կտրում Պապիի ճամփան։ Կարմիր pill՝
  պատմության շերտում (վերջին 6 + մոդալ, մինչև 60)։
- Աշխարհը՝ պրոցեդուրալ քաղաք. շենքեր (փայտակերպ + լուսավոր
  պատուհաններ), billboard-ներ, լապտերներ, մեքենաներ (GLB + գունավորում),
  ծառեր/թփեր, մայթ/ասֆալտի canvas տեքստուրաներ, երկնքի գրադիենտ։

## Ինչի էր տաքանում մոբայլը (ախտորոշում)

1. **UnrealBloomPass + EffectComposer** — ամեն կադրին մի քանի
   WebGLRenderTarget pass. մոբայլ GPU-ի ամենածանր բանն ա։
2. **MeshStandardMaterial + դինամիկ լույսեր** (placeLights, lightBudget) —
   PBR shading ամեն պիքսելին։
3. Ստվերներ, fog, պրոցեդուրալ գեոմետրիայի անընդհատ build/dispose։

Այս երեքն էլ 2.5D-ում ուղղակի ՉԿԱՆ — դրանք փոխարինվում են նկարած
շերտերով։ Հենց սա ա D-001-ի իմաստը։

## Pixi 2.5D-ի քարտեզագրումը

| Պրոտոյում | Pixi-ում | Ռիսկ |
|---|---|---|
| Հերոսը spritesheet | AnimatedSprite — ուղիղ | ցածր |
| Քաղաք/ճամփա 3D | Parallax շերտեր + մոտեցող սփրայթների scale (pseudo-3D) | միջին — զգացողության կալիբրում ա ուզում |
| Մեքենա GLB | Blender-ով նախապես ռենդերած ռակուրսների strip | ցածր (Blender ունենք) |
| Bloom | Baked glow սփրայթներ / էժան blur filter մենակ UI-ին | ցածր |
| Fog | Գրադիենտ overlay շերտեր | ցածր |
| Ստվեր | Blob սփրայթ (պրոտոն արդեն canvas shadowTex ա օգտագործում) | ցածր |
| Bet↔Run UI մորֆ | DOM/CSS ա — տեղափոխվում ա գրեթե անփոփոխ | ցածր |
| Կամերայի վարք | Վիրտուալ կամերա. շերտերի offset/scale/shake | միջին — feel spec ա պետք (T-0004) |

## Համապատասխանության դելտաներ (docs/stake-engine-ից)

- CASH OUT-ի իմաստը փոխվում ա (stateless կանոն, D-003 pending).
  կոճակն ու զգացողությունը մնում են, settlement-ը՝ նախաորոշված book-ից։
- Bet Replay-ը մտնում ա ճարտարապետության մեջ օր 1-ից։
- Ասեթները մերն են (օրիգինալ) — կարանք պահենք/վերամշակենք։ Մեկ նշում.
  թեման ռիսկե ա (հագուստ, ձեռնաշղթա) — approval-ը reviewer-ի
  հայեցողությամբ ա «poor taste»-ի հարցում. հիմնադրի գիտակցված որոշումն ա,
  ռիսկը գրանցված ա։
