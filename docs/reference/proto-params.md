## Օգտագործումը pixi-feel-ում

Pseudo-3D-ում 1:1 վերարտադրվում են. TARGET/ACCEL/MULT_RATE (ուղիղ),
կամերայի k=speed/TARGET կապը (FOV→պրոյեկցիայի exponent), shake 18Hz/amp1,
անիմ FPS 38 կապը արագությանը, ROAD_W/մայթ/լապտեր համամասնությունները
(մետրերը դառնում են z-միավոր), fog-ի mobile արժեքները (խորության
կտրվածքի հեռավորությունը), գույները։
