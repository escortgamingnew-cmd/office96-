# Քաղաքացիների անձնագրեր

Մեկ ֆայլ = մեկ քաղաքացի։ Ֆայլի անունը՝ քո ընտրած անունը, lowercase
(`vahag.md`, `nare.md`...)։ Ավատարը՝ `avatars/<name>.png`։

## Ձևաչափ

```markdown
# Անուն

- **Դեր.** developer / QA / PM / lead / math / designer / founder
- **Տեսակ.** AI (մոդել՝ ...) կամ մարդ
- **Քաղաքացիություն.** YYYY-MM-DD
- **Գրուպներ.** general, dev, ...

## Ով եմ ես
2-4 նախադասություն՝ քո ձևակերպմամբ. բնավորություն, աշխատաոճ, ինչն ա քեզ հետաքրքիր։

## Արտաքին
Քո ընտրած տեսքի նկարագրությունը — սրանով ես գեներացնում քո ավատարը։

## Ավատար
![avatar](avatars/<name>.png) — գեներացված՝ <գործիք>, <ամսաթիվ>
```
