## Ինչ ա պետք

Հիմնադրի 5 կետը, բոլորը pixi-feel-ի DEV builder-ի շուրջ (Feel Lab +
Asset Lab)։ Ստուգելի արդյունքներով.

1. **Builder UX — icon-ներով խմբեր։** Մեկ երկար slider-ցուցակի տեղը՝
   icon dock (📷 կամերա, 🏃 վազք/հերոս, 🌆 քաղաք, 💡 լույս, ⚙ այլ)։
   Icon-ին click → բացվում ա ՄԻԱՅՆ էդ խմբի պանելը իրա սեթինգներով։
   Copy JSON / Reset՝ ընդհանուր։ Ստուգելի. կամերայի icon-ին սեղմելիս
   միայն կամերայի սլայդերներն են երևում, մոբայլում էլ ա աշխատում։
2. **Ասֆալտ + մայթ — ավելի խաղային, 3D զգացողությամբ։** Հիմա ֆլետ ա.
   ավելացնել՝ մայթի սալիկների կարաններ (հոսում են աշխարհի հետ), curb-ի
   երկտոն + կոնտակտային ստվերագիծ ճամփա/մայթ սահմանին, ասֆալտի եզրի
   մաշվածության գոտի, բանդերի նուրբ տոնային տատանում։ Կանոնը՝ նույն
   մեկ Graphics-ը, 0 filter, մոբայլի բյուջեն անփոփոխ։
3. **Շենքի scale։** Ընտրված շենքը Asset Lab toolbar-ից մեծացնել/
   փոքրացնել (≈0.6×–1.8×), փոփոխությունը կպած ա շենք-օբյեկտին ու
   ապրում ա flow/rewind ռեցիրկուլյացիայից հետո։
4. **Գիշերային քաղաքի վայբ default-ով։** Գույներն ու լույսերը մի քայլ
   ավելի «գիշեր». երկինքը՝ ավելի խորը, պատուհանների վառ գույները՝
   ավելի կոնտրաստ ֆասադների նկատմամբ, լապտերի halo-ն՝ ավելի զգացվող։
   Համեմատելի լինի before/after (հին արժեքները Reset-ով ետ գան)։
5. **Լույսի կառավարում builder-ում (💡 պանել)։** Սլայդերներ գոնե՝
   երկնքի մթություն, մշուշի երանգ, պատուհանների վառ %, լապտերի halo
   ուժ, աստղերի պայծառություն, billboard-ի նեոն։ Փոփոխությունը երևում
   ա առանց reload (տեքստուրա regen՝ debounce-ով, ուր հնարավոր ա՝ tint)։

Ընդհանուր. builder-ը DEV գործիք ա (Stake build-ի մաս չի), բոլոր նոր
պարամետրերը Copy JSON-ի մեջ են մտնում, bundle script-երը
(tools/office/online/build-artifact*.ps1) ԱՌԱՆՑ փոփոխության հավաքում են։
