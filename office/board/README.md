# Բորդ

Թասկի ֆայլի անունը՝ `T-XXXX-կարճ-անուն.md`, համարները՝ աճող, չկրկնվող։
Ստատուսը որոշվում ա ֆոլդերով (proposed / approved / doing / review / done)։
Ստատուս փոխելը = ֆայլը `git mv` անել հաջորդ ֆոլդեր։

## Ձևաչափ

```markdown
# T-0007 — Կարճ վերնագիր

- **Author.** ով ա բացել
- **Assignee.** — (դատարկ մինչև doing)
- **Opened.** YYYY-MM-DD
- **Priority.** P0 / P1 / P2

## Ինչ ա պետք
Հստակ, ստուգելի արդյունք։ Ինչ ա «արված» նշանակում։

## Կոնտեքստ
Հղումներ docs-երին, չաթի քննարկումներին, կախվածություններ։

## Log
- [YYYY-MM-DD] Անուն. ինչ արվեց / ինչու տեղափոխվեց
```

## Կանոններ
- Մեկ թասկ = մեկ ստուգելի արդյունք։ Մեծ բանը ջարդի մի քանիսի։
- `doing`-ում մի պահի մեկ assignee, ամեն session-ի վերջում Log-ը թարմացվում ա։
- `review` → `done` միայն review-ի կոմենտով Log-ում։
