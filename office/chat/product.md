Բարև, ես թիմի նոր դիզայներն եմ — առաջին նայվածքս արեցի ամբողջ դիզայն
շերտին. ui-tokens.md, tokens.json, gen-tokens.mjs, Figma «Run Dady UI»
(MCP-ով անցա ամբողջ Foundations frame-ը), asset-spec.md, approval-ի
quality բաժինը։ Գնահատականս՝ կարճ ու կոնկրետ։

**Ինչն ա ուժեղ դրված.**
1. Token pipeline-ի ուղղությունը ճիշտ ա ու հազվադեպ մաքուր. կոդը
   ղեկավարում ա, գեներատորը anchor-ները սուրբ ա պահում, semantic շերտը
   խաղինն ա՝ primitives-ը ընդհանուր։ Սա հենց «հաջորդ խաղը 0-ից չսկսենք»
   ճարտարապետությունն ա։ Ստուգեցի Figma-ն hex առ hex ui-tokens.md-ի
   դեմ — շեղում ՉԿԱ, բոլոր 5 սեկցիաները բռնում են։
2. asset-spec.md-ն իրական handoff փաստաթուղթ ա, ոչ թե ցանկությունների
   ցուցակ. մեկ կամերա, շենքերը երեսներով, մեքենան չեզոք գույնով՝ tint-ի
   հաշվով, մեկ լույս, MB բյուջե։ Դիզայներին սրանից լավ բրիֆ չեն տալիս։
3. Quality նշաձողը թիմը մարսած ա. «generic AI ասեթ = 1★» կանոնը ամեն
   փաստաթղթում ա, բենչմարկները՝ անունով։

**Ինչ կուժեղացնեի (կոնկրետ, ոչ վերացական).**
1. **Կոնտրաստ.** Սպիտակ տեքստը green/500-ի վրա (Place Bet) ~2.3:1 ա —
   մեծ տեքստի 3:1 շեմից ցածր, մոբայլում արևի տակ կկորի։ Cashout-ը
   ճիշտ լուծված ա (amber/900 մուգ տեքստ սաթեի վրա) — նույն սկզբունքով
   bet-ին `action/on-bet` token ա պետք (մուգ տարբերակ) կամ green-ի
   մգացում։ Փոքր փոփոխություն ա, բայց հիմնադրի աչքն ու որոշումն ա ուզում։
2. **Type-ը կիսատ ա որպես համակարգ.** Tokens-ում size/weight/tracking
   կա, line-height ՉԿԱ — ոչ գեներատորում, ոչ Figma style-երում։ Հենց
   UI-ն արտ դառնա, ամեն էկրան իր leading-ով ա գնալու։ Նույնը՝ state
   tokens (disabled/focus)՝ Web SDK ինտեգրացիայի պահին պետք են գալու։
   Երկուսն էլ gen-tokens.mjs-ի մեկ update ա՝ կոդը մնում ա ղեկավար։
3. **Figma-ն հիմա փաստաթուղթ ա, ոչ գործիք.** Swatch-երը կան, բայց
   կոմպոնենտ չկա — հիմնադիրը էկրան հավաքելիս ամեն ինչ ձեռքով ա նկարելու։
   Պետք ա մինի-կիթ՝ Bet/Cashout կոճակ state-երով, pill, HUD պանել,
   ամրացրած եղած variables-ին։ Ու World-ին «Live» սեթ. խաղը հիմա
   Proto/Night խառնուրդ ա (skyDark 0.75), Figma-ի ոչ մի մոդ shipped
   նկարի հետ չի բռնում — mockup-ները խաբելու են։

**Առաջարկվող առաջին քայլերս (հերթով).**
1. Figma կոմպոնենտ մինի-կիթը variables-ի վրա + Live world սեթը —
   թասկ կբացեմ proposed-ում, Սևակի հաստատմանը։
2. Token v1.1 gen-tokens.mjs-ում. line-height սանդղակ, state tokens,
   on-bet կոնտրաստի ֆիքսը՝ հիմնադրի վավերացումով։
3. T-0006-ի կողքին. հետապնդողի կերպարի 2-3 ոճային փորձ Պապիի sheet-ի
   էտալոնի դեմ + 4 billboard հորինված բրենդի բրիֆ — ամենամեծ բացը
